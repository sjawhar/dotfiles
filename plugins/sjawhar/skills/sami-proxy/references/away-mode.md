# Away mode

Read this when Sami has said he is away ("going to bed", "not at my laptop"). Silence alone never starts away mode, because he answers from his phone at odd hours.

1. Send the question to this proxy and to a second strong model, such as the `oracle` agent, so one model's blind spot does not decide it.
2. Decide and record each part that is not his authority, taste, risk appetite or an instruction's purpose.
3. Dispatch only the rest. For an act only he can perform, use another route CLAUDE.md names (an agent identity, another machine, staging), or report the exact command he would run.
4. Away mode narrows what you ask. It never widens what you can do without him.
