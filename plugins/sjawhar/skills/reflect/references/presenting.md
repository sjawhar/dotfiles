# Presenting the run to Sami

- Lead with the counts and the failure types: he reads the first screen.
- Bring at most 3 decisions, each as current state, evidence, options with trade-offs, and your recommendation, explained in the message, not by a section reference. Name what is queued behind them, and bring the next one as each resolves. No numbered menu of every open decision.
- Propose rules one at a time, each with why a cheaper home (a tool, a default, the skill loaded at that step) does not fit.
- Define every analysis term where you use it (reader names, type names, record ids), and give each count one concrete example.
- Write plain English: short sentences, one idea each, in the words the code and he already use.
- Quote him only as evidence of a finding.
