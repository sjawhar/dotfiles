# Struggle beacon

If this skill disagrees with the code, a command's output or its `--help`, follow those and say which line of this skill is wrong.

- Loading this skill is the marker: it lets reviewers find where agents struggled without being told.
- Write one line starting `STRUGGLE:` that says what is hard or what was wasted, so the marker has a reason next to it.
- Then carry on with the task as you would have; do not stop or ask anyone because of this skill.

Query for reviewers: `references/query.md`.
